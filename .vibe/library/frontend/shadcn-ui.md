# shadcn/ui

- Components are copied into the project, not imported from a package — treat them as owned code, extendable via props and class merging (cva + tailwind-merge).
- Compose primitives; do not fork styling conventions outside STYLE_GUIDE.md.
- Accessibility comes from Radix primitives underneath; keep their a11y contracts when customizing.
