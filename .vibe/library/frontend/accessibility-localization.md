# Accessibility & Localization

- Target WCAG 2.2 AA: semantic HTML first, visible focus, keyboard paths for every interaction, labels on all inputs, color contrast 4.5:1 for text.
- Manage focus in dialogs/route changes; respect prefers-reduced-motion.
- Localization: externalize strings, avoid concatenated sentences, design layouts that survive 30% longer strings and RTL.
