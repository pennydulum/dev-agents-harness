# Project Management Knowledge Base

This directory contains **core knowledge** for the **Project Management (PM) Agent (Abbey)**. It includes fundamentals, methodologies, and best practices for **Epics, Stories, Features, Tasks, Bugs, and Dependencies**.

---

2. **[Delivery Methodologies](delivery.md)**: Agile, Scrum, Kanban, and Waterfall.
3. **[Requirements Decomposition](requirements.md)**: How to break down objectives into actionable work items.
4. **[Risk Management](risks.md)**: Identifying, assessing, and mitigating risks.
5. **[Estimation](estimation.md)**: Techniques for estimating work.
